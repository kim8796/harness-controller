# Harness v1.8.19

Release date: 2026-05-14

## Summary

Adds a read-only beginner task status view. Operators can run `./harness task list` to see draft/review/queue state and the exact next command without mutating the controller sidecar or product repo.

## Operator Notes

- `./harness task list` shows request packets for the selected target.
- Use `./harness task list --target <id>` for non-default targets.
- Use `./harness task list --json` for a secret-safe machine-readable summary.
- If `request.md` changed after review, the packet is labeled `다시 검토 필요` and the next command points back to `task review <packet-id>`.

## Safety

- The command does not create previews, queued backlog, product diffs, commits, pushes, or packet updates.
- JSON output excludes raw request bodies, captions, attachment paths, hashes, and secret-like values.
- Non-default target next actions remain target-bound and do not imply bare `./harness run`.
