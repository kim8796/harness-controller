# Harness v1.8.9

Release date: 2026-05-13

## Summary

Adds the external controller backlog-bound local product commit gate.

## Changes

- New command: `./harness target backlog commit <target> --run <implementation-run> --message "<msg>"`.
- Dry-run remains the default; `--apply` creates a local product commit only.
- The gate requires a completed sidecar backlog tied to the same implementation run.
- The gate verifies product HEAD, dirty paths, and product diff fingerprint before staging.
- Sidecar evidence records before/after HEAD, commit SHA, changed paths, no-push state, and rollback guidance.

## Safety

- Product push remains disabled.
- Telegram/Redis does not execute this command.
- The command does not move or edit backlog state.
- Product repo harness pollution remains a blocker.
