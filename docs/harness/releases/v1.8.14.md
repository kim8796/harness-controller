# Harness v1.8.14

Release date: 2026-05-14

## Summary

Adds the beginner external controller path: `./harness install`, `./harness task`, bare `./harness run`, and `./harness smoke implementation`. These commands hide the lower-level `target` machinery while still delegating to the existing target registry, sidecar backlog markdown, and implementation gate.

## Operator Notes

- `./harness install --repo <product> --id <target> --default` registers a product repo with the controller and does not write harness files into the product repo.
- `./harness task` creates an editable request draft; `task review` builds a preview, and only `task queue` writes canonical sidecar backlog.
- `task queue --auto` fails closed unless acceptance criteria, file scope, and validation commands are explicit.
- Bare `./harness run` uses the default target and delegates to `target run @default --implement-backlog-once`; it leaves local product diffs only and does not complete backlog, commit, or push.
- `./harness run --once` keeps the existing embedded starter smoke behavior.
- `./harness smoke implementation` uses a temporary product repo/target and does not run destructive cleanup.
