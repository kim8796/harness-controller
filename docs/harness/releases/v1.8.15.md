# Harness v1.8.15

Release date: 2026-05-14

## Summary

Improves beginner task intake for the external controller. Bare `./harness task` now starts a guided interview, task attachments can include validated image captions, and `task review --ai` writes advisory prompt/schema artifacts without launching a model or changing the deterministic queue gate.

## Operator Notes

- `./harness task` is the beginner entrypoint and creates a sidecar draft packet through the guided interview.
- `./harness task interview` supports non-interactive goal, summary, acceptance, file scope, validation, note, image, and caption flags.
- After `./harness task review latest`, `./harness task review latest --ai` writes `ai-review-prompt.md` and `ai-review-schema.json` in the packet. It does not execute Codex or another model and does not rewrite the deterministic review.
- `--ai-response <file>` can ingest an operator-supplied JSON response into separate advisory artifacts after sanitization.
- `task queue --auto` still uses only deterministic `review.json`, acceptance criteria, file scope, and validation commands.
- Product repos remain clean: task intake and review write only to the controller sidecar.
