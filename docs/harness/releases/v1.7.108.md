# Harness v1.7.108

Release date: 2026-05-12

## Summary

External controller target selection now supports operator-friendly aliases without changing the storage identity. Canonical `target_id` remains the only value used for sidecar directories, run locks, Redis relay keys, signed envelopes, and operator inbox paths.

## Changes

- Added `./harness target alias add <target-id> <alias>`, `remove`, and `list`.
- Added `./harness target set-default <target-id>` and `clear-default`; `@default` is an explicit selector, not a target id.
- Added optional `display_name`, `aliases`, and default selector metadata to target records.
- Updated Telegram routing to accept canonical id or `@alias` / `@default` while signing and storing only the canonical id.
- Preserved product-changing execution as disabled; `target run --once` remains read-only/no-op smoke.

## Safety

- Alias collisions, reserved names, invalid/path-like aliases, and unknown selectors fail closed.
- Product repos still receive no harness runtime/state files.
- No new parser, writer, scheduler, or relay ledger was introduced.
