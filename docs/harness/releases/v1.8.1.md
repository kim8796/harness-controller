# Harness Framework v1.8.1

Release date: 2026-05-13

## Summary

This release adds the first explicit product-changing smoke for the external harness controller while keeping the default target run path read-only.

## Changes

- `./harness target run <target> --once` remains read-only/no-op and continues to write state/evidence only to the controller sidecar.
- `./harness target run <target> --execute-once` now creates exactly one local product diff, `product-smoke-change.txt`.
- The product smoke records before/after HEAD/status, product diff path, disabled commit/push state, and rollback guidance in `targets/<id>/` sidecar evidence.
- Dirty pre-state, detached HEAD, branch mismatch, harness-marker files, unexpected product diffs, and product HEAD changes still fail closed.

## Safety

- No commit or push is performed.
- Telegram/Redis target routing is unchanged and does not trigger product-changing execution.
- Product repo harness runtime/state files remain forbidden.
