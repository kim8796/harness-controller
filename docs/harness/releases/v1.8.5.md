# Harness v1.8.5

Release date: 2026-05-13

## Summary

This release adds the first backlog-bound product-changing gate for external controller targets.

`./harness target run <target> --execute-backlog-once` selects the next queued auto item from `targets/<id>/backlog`, revalidates that exact sidecar backlog in the hidden RootContext path, and creates only the existing local smoke diff `product-smoke-change.txt`.

## Safety Contract

- This is a backlog-bound product diff smoke, not full AI product implementation.
- The selected backlog item is not moved, rewritten, completed, committed, or pushed.
- Product file content remains the existing deterministic smoke content.
- Backlog metadata is recorded only in controller sidecar evidence/report/status/outbox.
- Telegram/Redis owner commands can mention this instruction as text, but do not execute product-changing commands directly.

## Validation

- Focused CLI/controller/autonomy/Telegram/export tests cover success, missing backlog, manual-review backlog, mode conflicts, hidden backlog validation, and text-only Telegram instructions.
- Controller export includes the new command wording.
