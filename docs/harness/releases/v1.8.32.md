# Harness v1.8.32

Release date: 2026-05-28

## Summary

This release adds read-only fleet status, controller-local reusable learning memory, and localized document-first goal specs. Beginner usage remains `install -> goal -> watch`; `fleet status` is an operator projection for multiple registered targets.

## Changes

- Added `./harness fleet status` and `./harness fleet status --json`.
- Added `scripts/harness_fleet.py` for target readiness, goal, backlog, watch, operator-wait, memory, and publication/merge aggregation.
- Added deterministic promotion of compact reusable lessons into `targets/_global/memory/reusable-lessons.jsonl` and `reusable-index.json`.
- Kept global learning secret-safe and compact by promoting allowlisted event signals only.
- Added `./harness goal draft` and shorter `./harness goal from <goal-spec.md> [images-or-directories...]` for detailed spec/image-backed goals without writing to product repos.
- Added focused fleet tests and export/release-check coverage for the new module.
