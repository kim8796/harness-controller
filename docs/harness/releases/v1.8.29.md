# Harness v1.8.29

Release date: 2026-05-18

## Summary

This release continues the CLI code diet without changing the beginner UX. `./harness do` and `./harness task ...` keep their public behavior, while task intake orchestration moves out of the large CLI file.

## Changes

- Added `scripts/harness_task_cli.py` as the canonical home for beginner `do` / `task` orchestration, task-list rendering, and operator inbox task receipt handling.
- Kept `scripts/harness_cli.py` as the public parser and compatibility facade for existing command bindings and tests.
- Added focused `tests/test_harness_task_cli.py` coverage.
- Added the new task CLI module and tests to starter/controller export coverage and release-check paths.
