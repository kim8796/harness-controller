# Harness v1.8.3

Release date: 2026-05-13

## Summary

This release adds the explicit external product smoke push gate.

`./harness target run <target> --execute-once --commit --push` creates the deterministic smoke file, commits exactly `product-smoke-change.txt`, and pushes that smoke commit to the registered target branch. It is an advanced verification gate, not deployment.

## Contract

- `target run --once` remains read-only/no-op.
- `target run --execute-once` remains an uncommitted product diff smoke.
- `target run --execute-once --commit` remains a local unpushed smoke commit.
- `target run --execute-once --commit --push` is the only enabled product push path.
- Push mode resolves the registered branch upstream and uses `git push --no-verify <remote> HEAD:refs/heads/<registered-branch>`.
- Push mode does not force-push, push tags, push all refs, set upstream, create PRs, deploy, or perform automatic remote rollback.

## Safety

- Missing upstream, upstream branch mismatch, remote HEAD mismatch, dirty target, detached HEAD, branch mismatch, harness marker, missing git identity, and unexpected post-state fail closed.
- Target repo local `pre-push` hooks are bypassed for the deterministic smoke push, but product repo push-triggered remote automation may still run.
- Push rejection after local commit records the local commit SHA and failure without retrying or forcing the remote.
- Rollback is operator-reviewed: coordinate with the branch owner and use revert or repo-policy recovery.
