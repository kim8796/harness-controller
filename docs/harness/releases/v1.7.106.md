# Harness Release v1.7.106

Release date: 2026-05-12

This release completes the first Phase 5 step for the external controller: `./harness target run <id> --once` can now pass as a read-only/no-op smoke. It still does not execute product-changing autonomy lanes.

## Changes

- `target run --once` acquires the target lock, verifies the target, writes the dashboard, writes `targets/<id>/reports/target-run-latest.md`, proves the product git status remains unchanged, and exits 0 on success.
- Dirty target repos and branch mismatches are run blockers.
- Same-target lock conflicts remain fail-closed; different targets remain independently runnable.
- Product repos still do not receive harness state, runtime files, commits, or pushes.

## Non-Goals

- Product-changing autonomy execution remains disabled.
- External commit/push automation remains disabled.
- Telegram/Redis routing grammar is unchanged from v1.7.105.

## Verification

- Focused target CLI/controller/export tests.
- Controller export check and exported controller focused tests.
- Harness run validation and pre-push guard.
