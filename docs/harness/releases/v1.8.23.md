# Harness Controller v1.8.23

Release date: 2026-05-15

## Summary

This release improves the beginner task intake path so common frontend config-file scopes no longer become manual-review solely because of safe wildcard shorthand.

## Changes

- `task review` now expands a small allowlist of config aliases to exact candidate filenames.
- `task list` and `task review` show the scope adjustments and give the correct next command.
- New `task fix-scope <packet-id> [--apply]` can promote an already queued manual-review packet when deterministic review proves it is now auto eligible.

## Safety

- Canonical backlog parsing remains strict.
- Broad globs such as `src/*.ts`, `**/*.py`, and `*.*` are still not auto eligible.
- `.env*`, secret/token/key paths, and harness/controller runtime paths in File Scope still block auto queue.
- The repair command mutates only controller sidecar backlog metadata and never changes product files, commits, pushes, Telegram, or Redis behavior.
