# Harness v1.8.22

Release date: 2026-05-15

## Summary

Fixes START_HERE link routing in exported starter/controller bundles.

## Changes

- Generated root `START_HERE.md` is now a bundle-root entrypoint with `docs/harness/...` links.
- `docs/harness/START_HERE.md` no longer links to source-only `harness_guide.md`, which is not included in controller/starter bundles.
- Export tests now validate markdown file links for both root and detailed START_HERE documents.
