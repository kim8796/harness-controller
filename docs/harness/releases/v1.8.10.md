# Harness v1.8.10

Release Date: 2026-05-13

## Summary

`v1.8.10` is a controller export safety patch. It preserves v1.8+ controller release notes in `./harness controller export` so refreshing the private `harness-controller` repo from a clean bundle does not delete tracked release history.

## Changes

- Include v1.8+ `docs/harness/releases/v*.md` files in controller-safe bundles.
- Continue excluding older v1.7 embedded/project-specific release notes from controller-safe bundles.
- Add focused export coverage for previous/current controller release note preservation.

## Safety

- No target run, backlog transition, backlog commit, product push, Telegram, or Redis behavior changed.
- The patch corrects release/export retention only.
