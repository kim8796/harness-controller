# Harness Framework 1.8.7

Release Date: 2026-05-13

## Summary

`v1.8.7` is a controller release hotfix for the private `harness-controller` GitHub Actions workflow.

## Details

- Adds `requirements.txt` to the controller-safe export surface.
- Keeps `requirements.txt` out of starter bundles so new product repos do not inherit controller test dependencies.
- Leaves `v1.8.6` execution behavior unchanged: `target run --implement-backlog-once` is still the local-diff-only implementation gate.

## Reason

The private controller `v1.8.6` release attempt failed in GitHub Actions because the workflow installed dependencies with `python -m pip install -r requirements.txt`, but the controller export did not include that file.

## Safety

- No target execution behavior changes.
- No Telegram/Redis behavior changes.
- No product repo files are added.
