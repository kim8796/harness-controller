# Harness Framework 1.8.8

Release date: 2026-05-13

`v1.8.8` adds the explicit external controller backlog state transition gate.

## Highlights

- New command: `./harness target backlog transition <target> --status completed|blocked|manual-review`.
- `completed` is accepted only from a passing `--implement-backlog-once` run whose evidence still matches the current product HEAD and local product diff.
- The default is dry-run. `--apply` mutates only the controller sidecar backlog and writes sidecar transition receipt/evidence.
- Product commit, product push, Telegram-triggered execution, and automatic backlog completion remain separate gates.

## Validation

- Focused controller CLI tests cover dry-run, completed apply, stale product diff rejection, and manual-review transition.
- Controller/starter export checks include the new command and release note.
