# Harness v1.8.17

Release date: 2026-05-14

## Summary

Adds a Korean beginner help home for external controller users. Running bare `./harness` or `./harness help` now shows the short safe path instead of dropping operators into the full advanced command surface.

## Operator Notes

- `./harness` and `./harness help` show the beginner path:
  - `install`
  - `task`
  - `task review latest`
  - `task queue latest --auto`
  - `run`
  - `finish`
- `./harness --help` and subcommand `--help` remain the advanced argparse reference.
- The help path is static. It does not inspect targets, create `targets/**`, run models, or mutate product repos.

## Safety

- No target, Telegram/Redis, commit, push, or backlog semantics changed.
- Invalid subcommands still fail closed through argparse.
