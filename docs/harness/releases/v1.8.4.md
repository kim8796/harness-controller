# Harness v1.8.4

Release date: 2026-05-13

## Summary

- Added `./harness target run <target> --plan-once` as the external controller sidecar backlog plan gate.
- The command selects a queued auto backlog item from `targets/<id>/backlog` using the canonical backlog reader and writes the choice to the target run report.
- Product repo changes remain disabled: no product diff, commit, push, or general product-changing autonomy lane starts in this mode.

## Operator Notes

- Use `--once` for read-only RootContext smoke.
- Use `--plan-once` to see which sidecar backlog would be considered next.
- Use `--execute-once` only for the deterministic smoke-file gate.
- General product-changing backlog execution remains a later explicit gate.
