# Harness Release v1.8.27

Release Date: 2026-05-18

## Summary

Adds bounded `watch` smoke controls and a target-scoped watch status surface so real projects can be tested without guessing whether the loop is idle, blocked, or working.

## Changes

- Exposed `./harness watch --max-cycles`, `--idle-seconds`, `--no-telegram-drain`, and `--stop-on-idle`.
- Added `./harness watch --status`.
- Persisted watch heartbeat/status artifacts under `targets/<target-id>/watch/latest.json` and `latest.md`.
- Recorded goal, backlog, run, commit, PR publication, idle count, processed count, and next action in watch status.
- Kept code diet as a follow-up instead of extracting watch orchestration in this release.

## Safety

- Watch status artifacts are controller sidecar state only and are not written to product repos.
- Status output is redacted before writing and again before printing.
- `--stop-on-idle` exits cleanly when no active goal or executable backlog exists, avoiding misleading smoke hangs.
