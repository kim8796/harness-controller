# Harness v1.8.30

Release date: 2026-05-18

## Summary

This release keeps `./harness watch --status` useful after a goal finishes. Idle heartbeats still report the current idle state, but they no longer hide the last published transaction.

## Changes

- Added `last_*` transaction fields to `targets/<target-id>/watch/latest.json`.
- Preserved the last published backlog, run, commit, publication branch, and PR URL across later idle status writes.
- Added a separate last transaction section to `./harness watch --status` and `watch/latest.md`.
- Kept the expanded status payload secret-safe and controller sidecar-only.
