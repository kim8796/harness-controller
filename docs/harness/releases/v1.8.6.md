# Harness Framework 1.8.6

Release Date: 2026-05-13

## Summary

`v1.8.6` adds the first external controller real implementation gate:
`./harness target run <target> --implement-backlog-once`.

## Details

- Selects the next queued `Autonomy-Execute: auto` item from `targets/<id>/backlog`.
- Revalidates the selected backlog through the hidden external RootContext contract.
- Runs one AI implementer lane in the target product repo.
- Leaves local product diffs only; backlog completion, commit, push, and Telegram-triggered execution remain disabled.
- Stores implementer evidence, selected backlog metadata, product HEAD/status before and after, changed paths, and rollback guidance in the controller sidecar.

## Safety

- Product repos must remain free of harness code/state/secrets.
- Harness marker pollution fails closed.
- Existing smoke commands keep their previous meanings.
- Commit/push gates remain separate explicit modes.
