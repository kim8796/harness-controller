# Harness v1.8.11

Release Date: 2026-05-13

## Summary

`v1.8.11` removes generated coverage output from the canonical export source set. This lets clean exported controller repos pass `scripts/harness_export.py --check` without tracking stale local `coverage-summary.txt` files.

## Changes

- Removed `coverage-summary.txt` from `STATIC_EXPORT_SOURCE_PATHS`.
- Kept controller and starter bundles free of generated coverage output.
- Added controller export regression coverage for the exclusion.

## Safety

- No target run, backlog transition, backlog commit, product push, Telegram, or Redis behavior changed.
- This is a controller export/release hygiene patch only.
