# Harness v1.8.13

Release date: 2026-05-14

## Summary

`./harness target run <target> --implement-backlog-once` no longer passes the literal model `auto` to Codex. The default external implementation gate uses Codex's managed latest/default model and explicitly sets extra-high reasoning with `model_reasoning_effort="xhigh"`.

## Operator Notes

- Omit `--runner-model` for the default managed-latest Codex behavior.
- Pass `--runner-model <model-id>` when a specific model is required.
- Use `--runner-reasoning-effort minimal|low|medium|high|xhigh` to override the default reasoning effort.
- The gate is still local diff only: no backlog completion, commit, push, or Telegram-triggered implementation is enabled.
