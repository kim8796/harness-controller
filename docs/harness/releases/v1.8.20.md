# Harness Release v1.8.20

## Summary

- Added a controller distribution release gate: `./harness controller release-check`.
- The command is read-only and intended for the private `harness-controller` repo before tagging/releasing.

## Changes

- Checks controller export source readiness and `targets/` git-ignore behavior.
- Fails closed when tracked `.env*`, `targets/**`, generated exports, cache files, or live controller state are present in a controller distribution checkout.
- Supports optional `--run-lint` and `--run-pytest` focused checks.
- Emits secret-safe text and JSON output.
- Documents the new release gate in controller bundle README.

## Safety

- Does not mutate GitHub, tags, product repos, target sidecars, Telegram/Redis state, or env files.
- Source repo `harness_guard` remains the final source pre-push gate.
