# Harness v1.8.18

Release date: 2026-05-14

## Summary

Makes the first beginner action shorter. Operators can now register a product repo with `./harness install /path/to/product --id my-app --default`, while scripts can continue using the explicit `--repo` form.

## Operator Notes

- `./harness install /path/to/product --id my-app --default` is equivalent to the longer `--repo` form.
- Bare `./harness install` prompts for repo/id/branch/default only when run interactively in a TTY.
- Non-interactive bare `./harness install` remains a read-only status/next-action view.
- If positional repo and `--repo` point to different paths, the command fails before registering a target.

## Safety

- No target registry schema, Telegram/Redis, run, finish, commit, push, or backlog semantics changed.
- Product repo pollution guards remain unchanged.
