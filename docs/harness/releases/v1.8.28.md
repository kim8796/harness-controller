# Harness v1.8.28

Release date: 2026-05-18

## Summary

This release starts the watch code diet without changing the beginner UX. `./harness install`, `./harness goal`, and `./harness watch` keep the same behavior, while the implementation moves watch/run orchestration out of the large CLI file.

## Changes

- Added `scripts/harness_watch.py` as the canonical home for beginner watch/run orchestration and watch status helpers.
- Kept `scripts/harness_cli.py` as the public compatibility facade for parser bindings, command wrappers, and existing test monkeypatch points.
- Added the new watch module to starter/controller export coverage and release-check lint paths.
- Added `tests/test_harness_watch.py` so release-check can verify the extracted module directly.

## Verification

- `python3 -m pytest tests/test_harness_cli.py tests/test_harness_goal.py tests/test_harness_export.py -q`
- `python3 scripts/harness_export.py --check`
- `python3 scripts/harness_guard.py --mode pre-push --run-lint --run-pytest`
