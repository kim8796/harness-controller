# Harness v1.8.2

Release date: 2026-05-13

## Summary

This release adds the first explicit local product commit gate for external controller targets.

`./harness target run <target> --execute-once --commit` creates the deterministic smoke file, commits exactly `product-smoke-change.txt`, and records the result in the controller sidecar. It does not push.

## Contract

- `target run --once` remains read-only/no-op.
- `target run --execute-once` remains an uncommitted product diff smoke.
- `target run --execute-once --commit` is the only enabled commit path.
- Commit mode stages exactly `product-smoke-change.txt`.
- Commit mode skips hooks/GPG signing command-locally because this is a smoke artifact, not a shared product commit.
- The controller records before/after HEAD/status, commit SHA, commit diff, no-push state, and rollback guidance.
- Product push remains a future explicit gate.

## Safety

- `--commit` without `--execute-once` fails closed.
- Missing target git identity fails before product write.
- Dirty, detached, branch-mismatched, harness-marker, sidecar-escape, unexpected status, unexpected parent, and unexpected commit diff states remain blockers.
- Telegram/Redis owner commands do not trigger product commits in this release.
