# Autonomy Outbox

The autonomy loop writes one markdown summary per cycle here.

- File pattern: `runs/autonomy/outbox/<run-id>.md`
- Fixed metadata: `Task-ID`, `Lane`, `Result`, `Next-Recommendation`
- Optional policy metadata: `Policy-Proposal-ID`, `Approval-Class`, `Base-Policy-Version`, `Target-Policy-Version`
- Treat this directory as operator-facing runtime output, not committed evidence.
